What is saved?

The web timer saves favourites, daily checkmarks, time display and fishing region in this browser’s local storage. There is no account, cloud sync or link to your addon settings. Searches run locally and are not saved or sent to a server. Clearing this site’s browser data removes the saved choices. Private browsing and storage restrictions can prevent them from being retained.

Daily checkmarks reset at 00:00 UTC. The three Ley-Line Anomaly locations share one checkmark. A checkmark is your own record; the timer cannot detect completed events or claimed rewards.

What leaves the browser?

This timer loads its own HTML, JavaScript, schedule and original category symbols from the same website. It makes no GW2 API requests, uses no API key, analytics, external fonts or paid service, and sends no game-account information. The hosting provider receives ordinary connection information, including IP addresses, when it serves these files. See GitHub’s privacy statement. Following links to Discord, Nexus or GitHub opens those services under their own policies.

Schedule and limitations

Schedule snapshot: 10 November 2026, with reviewed project corrections exported on 16 November 2026. This is the same offline event catalog used by Tyria Chronicle. It describes scheduled starts and estimated windows, not live map progress, population or queues. Your device clock is used for countdowns. Local time follows your device’s time zone; UTC is available explicitly.

Unverified starts have no countdown. Seasonal events only appear within the dated calendar entries; later years are not guessed. You can choose a 24-hour window to see events further ahead. The page recalculates from the current time after you return from a background or sleeping tab.

The fishing clock follows standard outdoor Tyria or Cantha / Castora cycles. Select the region yourself: maps with fixed time and instances may differ. Web reminders are not implemented in this first version. Personal lists, templates, in-game reminders and meta train planning remain features of the in-game addon.

Amalgamated Gemstone

A small gemstone marks a verified reward choice, not a guaranteed automatic item drop. Shared daily chest limits still apply, and your reward claims are not detected. The tooltip and event details describe the relevant condition. Only reviewed choices are marked; a missing symbol is not a claim that the item can never drop there.
