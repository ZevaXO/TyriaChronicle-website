THE FIELD GUIDE

Screenshots preview the upcoming 0.2.14 design. Written functionality and download instructions are verified against public beta 0.2.13; some labels and placement may differ.

A little help for
the road ahead.

Practical steps for Tyria Chronicle 0.2.13-beta. Reviewed against the public README and release notes on 12 November 2026.

This guide covers documented beta behavior. Schedules are bundled estimates, not live map status. In-game confirmation of new features is still welcome.

01 / GETTING STARTED

From download to your first event.

Install the beta

  1. Use Windows x64 and install Raidcore Nexus separately.
  2. Open beta releases, read the newest release notes and download the attached TyriaChronicle-…-windows-x64.zip. GitHub’s “Source code” ZIP is not the addon. The standalone DLL asset is for Nexus updates.
  3. Close Guild Wars 2. Extract the downloaded ZIP.
  4. Copy TyriaChronicle.dll from the ZIP into your Guild Wars 2/addons folder.
  5. Start the game and enable Tyria Chronicle in Nexus.
  6. Click the clock icon or press Ctrl + Shift + E to open it.

Gw2Launcher and multiple accounts

Use the addons folder that Nexus uses for the game instance you launch. With localized execution this can be inside a numbered account folder, for example Guild Wars 2/Gw2Launcher/1/addons, rather than the main game's addons folder.

  1. Check your launcher configuration and that client's Nexus log to identify the active addons directory.
  2. Install Tyria Chronicle in each separate active addon directory where you want to use it.
  3. Launch the relevant client and verify Tyria Chronicle appears under Installed in Nexus.

Some launcher setups share or link folders. Several visible addons folders do not necessarily mean separate installations or separate settings.

Update without losing your lists

In Nexus, enable pre-release updates for Tyria Chronicle and choose Check for Updates. In 0.2.8 or newer, Update options → Open Nexus addons provides a shortcut; complete installation in Nexus. If that shortcut differs on your Nexus version, open the host addon menu manually.

For a manual update, close the game, download and extract the new release ZIP, then replace the existing DLL. Settings and lists are retained. The release’s SHA256 file is provided to verify its ZIP.

On 0.2.6 or 0.2.7, the old direct Update button does not work. Use Nexus’s own update control or replace the DLL manually. Users still on 0.2.0 need a manual update to gain Nexus update support.

What changed in 0.2.13?

Events use readable two-column cards. Details, Fishing, reminders and Quick help have clearer layouts. Category symbols are independently drawn; unapproved event portraits are excluded.

Your first five minutes

Open the event list, choose a time range, find an event and inspect its map and waypoint. Select a reminder, then try a personal list. No GW2 API key is needed.

02 / EVENTS

Find your next stop.

  1. Open Tyria Chronicle using its clock icon or shortcut.
  2. Choose how far ahead to browse. Presets include 1h, 2h, 4h and 24h; direct minute entry is also supported.
  3. Use the labeled Search field and the available filters to narrow the event list. Events are grouped by scheduled start time.
  4. Read the event’s map and short explanation. Copy its waypoint for use in game chat.
  5. After completing the event, mark Done today to pause its reminders until daily reset.

Tip: The search field’s Clear button removes only the search text, leaving other filters in place.

A listed or estimated active event is not confirmation that your map has started it. Completion is manual; the addon does not detect kills. Shackles of the Ancients has no countdown or reminders while its changed schedule is unverified. Festival dates cover 2026 only. Weekly Wizard’s Vault boss suggestions are provisional and not account-verified; check your in-game objective.

Sources: README · Search changes

03 / REMINDERS

A little preparation goes a long way.

  1. Turn the main Notifications switch on and ensure Mute is off.
  2. Choose reminders by category or select individual events.
  3. For a custom lead time, open an event’s details and uncheck Use default reminder time.
  4. Enter 0–60 minutes before that event. Use a longer lead when you want extra preparation time.
  5. Check Use default reminder time again to restore the shared default. Choices are saved between sessions.

Next reminder shows the earliest notification time. A later event with a longer lead can therefore appear before an earlier event. Changing the lead does not resend a start that has already been notified.

When the popup arrives

Copy the waypoint or mark the event Done today directly in the reminder popup. The popup is movable and optional sound is supported. Use Undo if you marked an event by mistake.

Done today lasts until 00:00 UTC. Ley-Line Anomaly shares completion across Gendarran Fields, Timberline Falls and Iron Marches. Marking any one done pauses all three; undoing from any location restores the group according to your saved reminder choices.

Sources: Individual reminder times · Shared Anomaly completion

04 / FISHING

Follow the light.

  1. Open the fish-marked Fishing button next to the clock.
  2. Manually choose your map region: Tyria or Cantha / Castora.
  3. Read the current phase, compact timeline and time remaining until the next phase.
  4. To receive alerts, enable Fishing reminders, select phases and choose a lead time. Dawn and Dusk are preselected, but fishing reminders start disabled.
  5. Keep main Notifications on and Mute off. Fishing alerts also appear in Next reminder.

Dawn and Dusk each last five minutes. Day/night fish can also be caught during those transition windows.

The clock follows standard outdoor schedules. It does not detect your map or automatically select a region. Fixed-time maps and instances can differ.

If a phase looks wrong

Check your selected region and local/UTC display setting. Report the map, region selection, display setting and the phase you observed through Help & feedback or Discord.

Sources: Fishing introduction · Current fishing notes

05 / PERSONAL LISTS

Turn a goal into a next step.

  1. Open My lists.
  2. Choose + New list → From a template or Empty list, then Create my list.
  3. Choose from documented templates for Obsidian armour, Aurene weapons, HoT materials or a daily meta round.
  4. Edit the list to fit your own priorities and mark event completion manually as you play.
  5. For an event train, open Share list to preview the next scheduled starts and waypoints.

Creating a list does not enable reminders. Use Enable reminders in its header to select its events without disabling your other choices. Notifications, Mute and Done today still apply. Settings and lists are retained when you update by replacing the DLL.

Templates are farming aids, not complete crafting recipes. A shared event train does not check travel time or event duration; review the route yourself.

Sources: README · Share list

PERSONAL PLANNING / IN DEVELOPMENT

Build a meta train around your group.

This feature is in development. The screenshot shows a work-in-progress interface, not a promise that it is available in the current public beta.

Choose the events for your personal list and enable Train planning in the editor. The preview includes planning options for map changes, a Choose events view and a Train preview tab.

Allow extra time between different maps and review warnings for Possible overlap or a Short map-change gap. These estimates use scheduled windows rather than measured completion times; adjust the time allowance for your group.

Changing list membership does not change your reminder choices. Planning does not change reminders or sharing. It helps you assess your chosen route; it does not guarantee that events or travel will fit together.

06 / SHARING

Bring the party along.

Share one event

  1. Open Share on an event.
  2. Review the message containing its scheduled start, name and waypoint.
  3. Choose Copy, then paste it into your chosen game chat channel.

Share an event train

  1. Open My lists → Share list.
  2. Review each stop’s next scheduled start and waypoint. The list uses one next start per event within 24 hours.
  3. Copy each preview message. Long trains split between events to keep waypoint codes intact.

Times use xx:MM rather than your local hour. The train preview does not validate travel time or event duration.

Copy-only sharing in 0.2.13

Sharing copies preview text to your clipboard. It does not open game chat or send game input. Paste manually into your chosen channel. Experimental Say from earlier betas has been removed pending clarification; earlier release notes describe historical behavior.

Sources: Event sharing · Train sharing · xx:MM format

07 / FAQ & TROUBLESHOOTING

When something needs a nudge.

Which download do I need?

The attached TyriaChronicle-…-windows-x64.zip on the newest beta release. Not the automatically generated Source code ZIP. Nexus is installed separately.

The addon does not appear. What should I check?

Confirm Windows x64, Nexus installation, and that the extracted DLL is in the addons folder used by Nexus for the client you launched. With Gw2Launcher localized execution this may be a numbered account folder such as Guild Wars 2/Gw2Launcher/1/addons. Check that client's Nexus log and verify Tyria Chronicle appears under Installed. Shared or linked folders do not necessarily mean separate installations or settings. Start GW2 and enable Tyria Chronicle in Nexus. Try the clock icon or Ctrl + Shift + E. If it still fails, report your version and what you tried.

Why am I not getting a reminder?

Check Notifications is on, Mute is off, and the event or category is selected. Check Done today and your lead time. For Fishing, enable its separate reminders and select the right region and phases. A time change does not resend an already notified start.

Why does Next reminder show a later event?

Since 0.2.12 it chooses the earliest notification time, including preparation lead. A later event with a long lead may need to notify first.

Why are all three Ley-Line Anomaly locations marked done?

They share daily completion. Undo from any location to restore the group. Completion resets at 00:00 UTC and is marked manually.

The update is stuck on Updating.

The old button in 0.2.6/0.2.7 cannot complete this update. Use Nexus Check for Updates with pre-release updates enabled, or close the game and replace the DLL from the newest ZIP. Version information can take a few minutes to propagate.

Do I need an API key or GitHub account?

No GW2 API key is needed. Public beta downloads do not require a GitHub account. Discord is the primary feedback channel; GitHub issues are optional and require an account.

Why is there no Shackles countdown?

In 0.2.13, Shackles of the Ancients countdowns and reminders are paused until its changed schedule is verified. Its details remain available.

Where did Say go?

Experimental Say was removed in 0.2.13 pending clarification. Sharing is now Copy-only; paste manually into your chosen game chat channel.

Are these live event timers?

Schedules are bundled estimates, not live map status. Estimated active windows do not guarantee an event is running on your map. Fishing follows standard outdoor schedules.

Does it hide during full-map view or cutscenes?

Separate full-map and cutscene hiding is not implemented in the current beta.

What should I include in a bug report?

The version from Settings, your steps, expected result and actual result. For event timing, include date, map, time and time zone. For Fishing, include region, local/UTC setting and observed phase. A cropped screenshot helps; remove personal details. Help & feedback can copy basic troubleshooting information.

Source: Current release notes and the linked topic sources above.

09 / ABOUT & SUPPORT

Made by an adventurer, for adventurers.

Tyria Chronicle is an independent Guild Wars 2 companion addon by ZevaXO, offering event timers, waypoint reminders, fishing clocks and personal goal lists. It is an early beta developed with AI-assisted code and documentation. The category symbols and header clock are original AI-generated generic artwork, created from text-only concepts without game-image references. They are not official game assets.

Ask for help, report problems or share ideas on Discord. You may also open a GitHub issue. The public repository contains downloads and release information; development source remains private.

This is an independent fan project, not affiliated with ArenaNet, NCSOFT, Raidcore or Blish HUD. Guild Wars 2 and related game content belong to their respective owners. Package licenses and third-party notices are included in the addon ZIP.

10 / PRIVACY & COOKIES

A simple website, with a small footprint.

This website does not set cookies, use analytics, load third-party fonts, create accounts or store guide searches. Search runs locally in your browser. No game account information or API key is requested by this website.

Following download, Discord, Nexus or GitHub links takes you to external services governed by their own privacy policies. A hosting provider may process connection information such as IP addresses in server logs. For the proposed GitHub Pages hosting, see GitHub’s privacy statement.

This describes this website, not the addon or external services. The addon stores preferences locally and checks the public GitHub version feed after startup and hourly. GitHub receives ordinary connection metadata. No account telemetry is collected and no GW2 API key is needed. This website does not make those addon update requests. For questions, contact the project through Discord.
